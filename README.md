# AI Commerce Platform

Working product name: Raqana.

An AI-powered omnichannel commerce SaaS for merchants and brands.

The platform can either provide a merchant with a hosted online storefront
or integrate with an existing commerce stack, while unifying products,
inventory, orders, customers, conversations, support, and AI-powered
selling across web, WhatsApp, Instagram, and future channels.

## Status

Early design and architecture phase.
